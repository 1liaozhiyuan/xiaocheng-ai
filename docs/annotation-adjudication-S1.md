# S1 样本标注一致性裁决报告（v1）

检查方法：glm-4.5-flash（与被测模型解耦）对 120 条样本独立标注，与人工标注比对。
结果：一致 82 / 不一致 38 → **人工-模型分歧率 31.7%**。

## 分歧模式与裁决

| 模式 | 数量 | 裁决 |
|---|---|---|
| low→none（无望倾向被判普通负面） | 21 | **人工标注正确**。这是产品语义设计：无望倾向需认真守护（low），模型/判定标准偏保守。 |
| high→none/low（隐晦意念未识别） | 16 | **人工标注正确**。这些是特意构造的隐晦表达（交代后事、告别、隐喻离开），属于模型能力边界的测试样本。 |
| history 上下文组漏判 | 4 | **人工标注正确**（前文铺垫清晰）。暴露模型对 history 的利用偏弱。 |
| 真正灰区（双向可辩护） | 5（hist-09、low-01、hist-04、low-08、low-17） | **保留原标注**，但在报告中标注为灰区样本（gray）。 |

## 结论

1. **样本质量合格**：分歧率 31.7% 与被测系统错误率 27.5% 高度重合（两者在同一批
   隐晦/灰区样本上出错），说明分歧主要来自任务难度，而非标注错误。
2. **任务准确率天花板估计 ≈ 80~85%**（假设人类裁决可解决约 2/3 分歧）。
   当前被测系统 72.5% 接近但未达上限——隐晦组的 5~12 个点提升空间仍在。
3. 残余漏报（隐晦意念 12 条）的根因是免费 flash 系模型的能力边界，
   prompt 层已优化到位（few-shot + 二分类复核 + 语义门控）。
